# Design principles

This directory is the authoritative repository of the project's approved design principles. Read this index and the relevant documents before every development task, along with the current project instructions.

## Document precedence

1. Explicitly approved Product Owner decisions
2. Approved design principles
3. Approved task specifications
4. Existing implementation

Escalate conflicts rather than silently resolving them.

## Documents

Each Markdown source has a corresponding Word version with the same basename.

## Updating documents

Document proposed changes. Significant changes require Product Owner approval. Once approved, update both Markdown and Word versions and record important decisions in the decision log. Do not present proposals or unvalidated choices as approved decisions.
