# Seeded island setup

The island uses the stable hex IDs and edge-based neighbor relationships in [board geometry](BOARD_GEOMETRY.md). The standard setup has 19 cells: four forests, three hills, four pastures, four fields, three mountains and one desert. The expanded 5–6 player setup has 24 cells: five forests, four hills, five pastures, four fields, four mountains and two deserts. Desert cells have no number token; the robber starts on one of the deserts. Both layouts reject assignments where two 6 or 8 tokens share an edge.

Enter an integer seed from 0 through 4294967295 and select **Apply seed** to reproduce a board. **New random board** uses the browser's cryptographic random source to select a seed. The current seed appears above the board; the initial seed is 1. Terrain and resources are labeled on the board; mountains are abbreviated Mtns. A text list provides the same details to assistive technology. Changing a board does not synchronize it with other peers.

`generateBoardSetup(seed, layout)` is a pure function; `layout` defaults to the standard board. Its version, `mulberry32-fy-rejection-v2`, identifies the deterministic Mulberry32 unsigned 32-bit stream, Fisher–Yates shuffles and rejection-sampled indices. Geometry iteration order is ascending axial q then r. The terrain multiset is shuffled first. Token shuffles are tried in order against the existing `neighborIds`; the first valid assignment is accepted. At most 1000 token shuffles and 128 random draws per index are attempted. Failure raises an error rather than weakening the adjacency rule. After a valid token assignment, port types are shuffled onto fixed, well-spaced coastal edges; each port belongs to both endpoints. The standard board has nine ports: four generic 3:1 ports and one 2:1 port per resource. The expanded board has eleven ports: six generic 3:1 ports and one 2:1 port per resource. The version and seed are returned with the setup; changing this algorithm requires a new version. The generator is for reproducibility, not cryptographic security.

The counts and red-number spacing follow the [CATAN base-game rules](https://www.catan.com/sites/default/files/2021-06/catan_base_rules_2020_200707.pdf). The layout is not a statement of additional game or balancing rules.

To check locally, run `npm install`, `npm run typecheck`, `npm test`, `npm run build`, and `npm run dev`. At desktop and narrow mobile widths, inspect both the 19-cell standard board and 24-cell expanded board, try a seed twice, generate a new board, and check that the previous seed plus layout reproduces the previous setup. The private room and manual signaling controls remain available separately.
