# Hex Island Game

A planned browser-based multiplayer board game inspired by Catan, for private use. The project includes a deterministic island-board geometry and a responsive prototype renderer, along with multiplayer connectivity experiments. Gameplay rules are not yet implemented.

Start with [design principles](design_principles/README.md) and [project instructions](AGENTS.md) before development.

See [board geometry](docs/game/BOARD_GEOMETRY.md) for the prototype model and deferred decisions.
