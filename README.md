# Hex Island Game

A planned browser-based multiplayer board game inspired by Catan, for private use. The project includes a playable MVP rules engine, seeded board, local hot-seat mode, and a host-authoritative private-room interface. Multiplayer requires the configured signaling service and friend-game validation across real networks.

Start with [design principles](design_principles/README.md) and [project instructions](AGENTS.md) before development.

See [game rules, multiplayer and deployment](docs/game/GAME_MVP.md), [board geometry](docs/game/BOARD_GEOMETRY.md), and [seeded board setup](docs/game/BOARD_SETUP.md).
